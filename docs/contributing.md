# Contributing Guide

Please see our comprehensive [Contributing Guide in the GitHub repository](https://github.com/bdperkin/ecu-hockey-calendar/blob/main/CONTRIBUTING.md) for full instructions on setup, testing, code quality, and submitting pull requests.

## Key Guidelines

1. **Branching Model**: All commits must be made on feature/fix branches; merging into `main` requires pull requests.
2. **Commit Convention**: Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `chore:`, `test:`, `refactor:`).
3. **Quality Standards**: 100% test coverage, strict `ty` type checking, and clean `ruff` formatting must be maintained at all times.
